## 1. 概述

本目录包含软件全生命周期各阶段的文档模板，共 **13种**，覆盖从计划到总结的完整流程。所有模板遵循统一的格式规范，便于文档编写和维护。

---

## 2. 文档命名规则

所有模板文件采用统一命名格式：

```
[文档标识]-[文档名称]-模板.md
```

**示例**：`SRS-软件需求规格说明-模板.md`

## 5. 文档深度说明

每个文档类型分为两个深度级别：

### 概要级文档

**适用场景**：立项阶段、初步设计、快速原型

**内容特点**：
- 仅包含核心章节
- 描述简洁明了
- 满足基本需求描述

**章节标识**：模板中标记为"概要级骨架"的章节

### 详细级文档

**适用场景**：开发阶段、正式评审、交付归档

**内容特点**：
- 包含完整章节
- 描述详细深入
- 包含技术细节和可追踪性

**章节标识**：模板中标记为"详细级追加"的章节

## 6. 使用指南

### 6.1 选择模板

根据项目阶段和文档类型选择对应的模板文件。

### 6.2 填写模板

1. 复制模板文件到项目文档目录
2. 替换模板中的占位符（如 `[项目代号]`、`[项目全称]` 等）
3. 根据文档深度要求填写相应章节

### 6.3 文档标识格式

```
[项目代号]-[文档标识]-[序号]
```

**示例**：`PROJ001-SRS-001`

### 6.4 版本管理

采用三级版本号格式：

```
VX.Y.Z
```

- **X**：重大版本变更（文档结构调整）
- **Y**：功能版本变更（内容新增/修改）
- **Z**：修订版本变更（错误修正）

### 6.5 质量度量

所有文档完成后，需按照 [AGENTS.md](../AGENTS.md) §6 中的质量度量指标进行自检。
