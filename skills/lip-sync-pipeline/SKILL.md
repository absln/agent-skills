# lip-sync-pipeline

音频 → 口型时间轴 → 逐帧驱动角色。核心原则：**以秒级 cue 为唯一事实来源**、**素材按几何对齐与归一化**、**动作确定性可复现**。

---

## 适用场景

| 触发条件 | 说明 |
|---|---|
| 音频要变口型动画（Rhubarb/Papagayo 等） | 视觉音素 → 帧序列 |
| 换口型素材包（不同画风/更多形状） | 需要中心对齐 + 尺寸归一化 |
| 口型"硬跳"、形状丑、大小/位置不对 | 过渡帧、形状映射、几何口径问题 |
| 角色要"活着"（呼吸/点头/手势/眨眼） | 驱动层动作模型 |
| 多角色对话（谁说话谁动） | 用语音段/包络驱动，各角色独立 performance |

| 不适用 | 原因 |
|---|---|
| 只需音频转写（不做口型） | 属 ASR 任务 |
| 三维/骨骼软件绑定（Live2D/Spine） | 工具链不同 |

## 执行步骤

### 1. 音频规范化（硬前置）

```
任意音频/视频 → 单声道 16k wav（识别器可能只吃 wav/ogg），并做响度归一
同时保留原始采样率/声道的副本，供最终混音（不要把分析用低采样率轨拿去出片）
```

### 2. 口型识别（确定性优先）

```
固定单线程（多线程会因调度不同产出不同 cue 数）
输出格式：优先 JSON 秒级 cue，不要用其它工具导出的帧号（帧号约定各异且会丢首帧）
```

### 3. cue → 帧序列（自行量化）

用技能自带脚本，不要自己写量化循环：

```bash
python scripts/cells_from_cues.py --cues cues.json --fps 24 --total-frames 548     --shape-frame '{"MBP":27,"etc":9,"E":11,"AI":30,"O":7,"U":14,"FV":6,"L":13,"WQ":4,"rest":25}'     --out cells.json
```

```
规则：第 k 帧覆盖 [k/fps,(k+1)/fps) → 取该区间起始时刻所属 cue
输出：逐帧帧号 + runs（{from,count,shape}），可直接写关键帧表/时间轴
cues.json 两种写法都收：[{start,end,shape}, ...] 或 {"cues":[...]}
```

### 4. 口型素材换装（外部素材包）

> **事实源边界**：素材包的坐标空间、bbox、对齐方式（canvas/center）、尺寸归一化口径、帧号索引契约，
> 唯一事实源是 `asset-pack-contract` 技能——本节只讲"换口型时怎么用"，冲突时以其为准。

```
形状键固定为语义键（如 AI/E/O/U/FV/L/MBP/WQ/etc/rest），不要用素材自己的层名当键
  → 上层（映射表/驱动/打包）只依赖语义键，换素材只改"语义键→帧号"
新素材与角色**必须做两件事**：
  1) 中心对齐：外部口型图表（每个嘴画在图纸固定位置）按"锚点中心"落到角色嘴位，不能用它自身画布坐标
  2) 尺寸归一化：两包画布/画风不同，按**被用形状的宽度中位**配比（不要用整体外框，会被最宽形状撑大）
映射可用数据驱动：把已知正确包与目标包都按「开口度 h/w + 相对宽度 w/w_max」归一化后配对
```

### 5. 过渡帧（消除硬跳）

```
形状切换时：新旧形状**交叉溶解** + 双方口径互相插值，持续 2~3 帧
验收：嘴部紧框的逐帧平均差峰值显著下降（实测 21 → 16）
```

### 6. 驱动层（动作模型）

```
所有位移在"设计空间"（=最终渲染像素）里算，最后映射回场景坐标 → 幅度直观、与场景解耦
层级：口型/五官作为**头部子节点**（绕颈枢轴同一刚体变换）；后发等可 0.6 衰减
呼吸：躯干低频正弦；静音时保留 25% 微动（否则沉默一方像"死"）
手势：按"每语音秒次数"排程，左右臂交替，每段 ~0.8s 抬起-放下
眨眼：按频率排程（需素材有眼睑层）
性格反差：把"头幅/手势频率/口型开合"做成每角色参数（同一驱动演出不同性格）
确定性：所有随机排程用**固定 seed** → 同段重跑逐字节一致
```

### 7. 验收

```
逐字节可复现：同段重跑 md5 一致
动作生效：头框内相邻帧差异像素数 > 0（实测 1.8–7.4 万像素/帧）
口型落位：嘴框中心必须落在头框内（自动判定，不靠肉眼）
成片级：渲染帧与"设计图"逐像素比对（alpha 不一致率、RGB 平均差）
```

## 常见错误

| 问题 | 现象 | 处理 |
|---|---|---|
| 用多线程识别 | 同输入两次结果不同（cue 数 46→44） | 固定单线程 |
| 用工具导出的帧号 | 首帧被强制写成静止、整段偏移 | 以秒级 cue 自行量化 |
| 换素材后嘴飞出脸外 | 外部口型图表按自身 bbox 定位 | 改"中心对齐到锚点" |
| 换了素材嘴明显变大/变小 | 用整体外框配比（含最宽形状/水平错位） | 用**形状宽度中位**配比 |
| 键名换成素材层名 | 上层映射查不到键（`KeyError`） | 形状键保持语义键 |
| 驱动按帧号索引却只装用到的帧 | 越界报错 | 口型列表**按帧号装全部帧** + 越界断言 |
| 沉默角色完全静止 | 观感像"死" | 静音保留 25% 微动 |
| 逐特征独立判定口型/动作 | 边界抖动、段数暴涨 | 用带切换代价的全局最优（Viterbi）或平滑+最短段约束 |
| 提取器每次重建 | 150 个窗口从秒级拖到分钟级 | 复用提取器实例 |

## 输出

```
<work>/lip/<角色>.lip.json        秒级 cue + 形状/帧号 + 统计
<work>/cells/<角色>.cells.json    逐帧帧号 + runs（可直接写关键帧表）
<work>/drive/<角色>/frames/*.png  逐帧角色图（含口型/动作，已烘焙）
<work>/drive/<角色>/verify.json   自检（头部位移、变化帧数、排程统计）
```
