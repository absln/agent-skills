# 16:9 演示文稿版式速查

> 画布 13.333 × 7.5 英寸（12192000 × 6858000 EMU）。所有数值单位为**英寸**，即代码里 `Inches(x)` 的 x。

---

## 1. 版心与网格

| 区域 | 坐标 | 说明 |
|------|------|------|
| 左右留白 | 1.30 | 版心宽 = 13.333 − 2×1.30 = **10.733** |
| 标题基线 y | 0.40 | 高 0.85，标题下划线在 y=1.28 |
| 正文顶 y | 1.55 | 高 5.20（到 y=6.75） |
| 页脚 y | 6.95 | 仅需页码时用 |
| 编号徽标 | x 0.40，y 0.48 | 左上角 `01`/`02`…（Arial） |

**三栏网格**：版心 10.733 分 3 栏 → 栏宽 3.31，间隔 0.40（`x = 1.30 + i×3.71`）
**两栏网格**：栏宽 5.17，间隔 0.40

---

## 2. 字号阶梯（pt）

| 用途 | 字号 | 备注 |
|------|------|------|
| 封面主标题 | 44 | 加粗，主题金色/深蓝 |
| 结尾主标题 | 40 | |
| 内容页标题 | 28 | 加粗 |
| 章节页大编号 | 60 | Arial，低对比色 |
| KPI 数值 | 40 | Arial |
| 导语 / 结论句 | 22 | |
| 正文 | 18 | 行距 1.15~1.3，段后 10pt |
| 次要 / 图注 | 14 | 灰色 |
| 脚注 | 11 | |

> 一屏禁超两种字号层级（标题 + 正文），多余层级用**颜色/加粗**区分。

---

## 3. 容量上限（防溢出，经验值）

| 元素 | 上限 |
|------|------|
| 内容页正文 | ≤ 6 行 / ≤ 200 字 |
| 单行 | ≤ 28 字（超了自动折行，行数按 28 字/行折） |
| 标题 | ≤ 18 字 |
| 表格 | ≤ 6 行 × 4 列，字号 12~14 |
| 图片 | 宽 ≤ 10.7；与文字同页时图宽 ≤ 5.2 |
| KPI 卡 | 3~4 张，每张 1.7 高 |

**经验公式**：可容纳行数 ≈ floor(5.2 × 72 / (字号 × 1.3))；18pt → 约 15 行，但视觉上限取 6 行。

## 4. 常用版式清单

| 版式 | 方法 | 适用 |
|------|------|------|
| 封面 | `cover(title, subtitle, meta)` | 第 1 页 |
| 目录 | `title_content("目录", [...])` | 4 章以上才需要 |
| 章节页 | `section(num, title, en)` | 每章开头 |
| 要点页 | `title_content(title, items)` | 主力版式 |
| 数字页 | `title_content(...)` + `kpi([...])` | 结果/成效 |
| 图文页 | `title_content(...)` + `image(s, path, x, y, w=5.2)` | 实物照片/截图 |
| 表格页 | `title_content(...)` + `table(s, data, ...)` | 对比/参数 |
| 结尾页 | `closing(title, line, note)` | 致谢/演示邀请 |

## 5. 要点语义样式（`deck.bullets` 的 style）

| style | 颜色 | 加粗 | 用途 |
|-------|------|------|------|
| `body` | 正文色 | 否 | 陈述事实 |
| `accent` | 强调色 | 是 | 关键结论、本方案独有 |
| `dim` | 次要色 | 否 | 已废弃方案、补充说明 |
| `lead` | 强调色 | 是 | 小标题式引导句 |
| `title` | 标题色 | 是 | 同 `lead`，用于深色底 |

**规律**：一页内 `accent` ≤ 2 处，否则强调失效。

---

## 6. 时长 → 页数

| 时长 | 页数 | 结构 |
|------|------|------|
| 5 分钟 | 6~8 | 封面 + 3 内容 + 结尾 |
| 8~10 分钟 | 10~14 | 封面 + 目录/章节 ×2 + 6~8 内容 + 结尾 |
| 15~20 分钟 | 18~24 | 完整章节结构 |

> 规则：**1 页 ≈ 40~60 秒**（中文口播约 200 字/分钟）。

---

## 7. 配色规则

| 角色 | midnight（深色科技） | light（浅色商务） |
|------|---------------------|------------------|
| 背景 | `#0E1B33` | `#FFFFFF` |
| 次级背景 | `#162A4A` | `#F2F6FB` |
| 标题 | `#F5C542` 金 | `#123A6B` 深蓝 |
| 正文 | `#FFFFFF` | `#222A35` |
| 强调 | `#5FB4E8` 亮蓝 | `#1D9AF8` |
| 次要 | `#9FB2CC` | `#6B7A8C` |

- 深色底：正文白色、强调亮色；**不要**用深灰字（对比度不足）
- 每页颜色 ≤ 4 种（背景 + 标题 + 正文 + 强调）
- 主题色与品牌/作品主色一致（如太空主题 → 深蓝 + 金）
