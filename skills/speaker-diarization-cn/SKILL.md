# speaker-diarization-cn

一段混音 → 每人一条轨 + 段落表。**先判断素材能不能分**，再谈算法；验收用真值回归。

---

## 适用场景

| 触发条件 | 说明 |
|---|---|
| 一段对话音频要自动分出说话人 | 替代人工分轨 |
| 分离结果"归属错"（谁说的判断错） | 多为判别特征不可分，见「可分离性诊断」 |
| 边界抖动、同一人被切碎 | 逐帧独立判定的典型症状 |
| 需要给下游（口型/TTS/字幕）提供分轨与时间段 | 输出等长分轨 + JSON 段落表 |

| 不适用 | 原因 |
|---|---|
| 已有人工分轨 | 直接用人给的轨 |
| 需要语音转写内容 | 属 ASR 任务（本技能只做"谁在何时说"） |

---

## 执行步骤

### 1. 规范化与真值准备

```
音频/视频 → 16k 单声道 wav（同时保留原采样率/声道副本）
真值：用**各说话人独立轨**的语音段（能量 VAD）当 ground truth
回归输入：把各轨按时间相加合成"混音单文件"（互补轨相加 ≈ 原始对话）
```

### 2. VAD 定语音区间（帧级）

```
能量 VAD（10ms 帧、阈值与业务一致如 -50dBFS、最短语音/静音可调）→ 语音区间
作用：给出精确的起止（比滑窗分类的量化边界准得多）
```

### 3. 区间内定说话人（基频 / 嵌入二选一或融合）

```
基频法（男/女或音域差异大时首选，稳且无需模型）：
  10ms 基频轨迹 → 区间内逐帧按"最近参考基频"计代价 → **Viterbi**（切换代价）分段
滑窗嵌入法：0.8s 窗 + 参考音轨嵌入做最近邻分类
融合/兜底：先跑「可分离性诊断」，再决定用哪种
```

### 4. 角色归属（把簇贴上人名）

```
参考音轨（每人的一段干净语音）→ 取**有声窗口**的嵌入均值/基频中位
按余弦相似度或基频比匹配到簇；2 人时贪心唯一匹配
⚠️ 参考音轨要用"有声窗口"，别用整文件（静音会把嵌入稀释成噪声）
```

### 5. 可分离性诊断（**必做**）

```
指标：两个参考音轨的嵌入相似度（越低越好）
经验值：两个明显不同的合成音色 ≈ 0.42；同一音源/很像的两人 ≈ 0.75
>0.55 ⇒ 自动分离不可靠 → 提示改用基频法并要求人工核对段落表
```

### 6. 切轨与输出

```
按段落把原音频切片叠加到等长静音轨（与原文件同采样率/声道）→ 可直接喂口型/混音下游
```

### 7. 真值回归评测

用技能自带脚本，不要手算：

```bash
python scripts/eval_diarization.py --pred pred.json --gt gt.json --total 22.8 [--hop 0.02]
```

```
输入：pred.json = {"segments":[{"start":..,"end":..,"speaker":"wife"}, ...]}
      gt.json   = {"wife":[[start,end],...], "husband":[[...],...]}
输出：帧级（默认 20ms）逐人 precision / recall / F1、语音总时长偏差、
      边界按最大重叠配对后的起止 MAE
经验基准：干净双音色（不同 TTS 音色）F1 ≈ 0.87；声音很像的素材 ≈ 0.73
```

### 8. 依赖与前置

```
ffmpeg       解码/重采样/切片（音频/视频 → 16k 单声道 wav、按段切轨）
python       3.10+；评测脚本纯标准库，无需 numpy
嵌入模型     滑窗嵌入法需自备（如 resemblyzer / funasr），本技能不绑定具体实现；
             只有基频法（纯信号处理，无需模型）才能零依赖跑通
```

## 常见错误

| 问题 | 现象 | 处理 |
|---|---|---|
| 用分段器直接定归属 | 无静音衔接的两人被并成一段（整段只给一个标签） | 用 VAD 定区间 + 区间内逐帧判定/全局最优 |
| 用整文件算参考嵌入 | 相似度普遍虚高、归属乱跳 | 只用**有声窗口** |
| 逐帧独立判定 | 段数暴涨（6 段 → 20+ 段）、边界抖 | Viterbi（切换代价）或平滑 + 最短段约束 |
| 只在混音上做 VAD | 相邻说话人无静音时被并段 | 区间内做说话人切换检测 |
| 用"改动中心/固定框质心"当指标 | 指标不动或误导 | 用相邻帧差异像素/帧级 F1 这类可分辨指标 |
| 提取器每次加载 | 分钟级耗时 | 复用提取器实例 |
| 忽略素材可分离性 | 反复调参仍不收敛 | 先跑诊断；不可分就退回人工/多轨输入 |
