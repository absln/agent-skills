# 概要设计 检查清单

> 做概要设计时，逐项覆盖。**重点：模块间关系**（系统是模块的复杂组合，关系最易漏）。

## 必须覆盖的维度

| 维度 | 检查点 |
|------|--------|
| 模块划分 | 有哪些模块、各自职责、标识符（类名/工程） |
| **模块间关系** | 谁调用谁、数据怎么流转、依赖关系（**最易漏，必须画图**） |
| 功能×模块矩阵 | 每个功能需求由哪些模块实现（√ 矩阵） |
| 接口设计 | 用户接口、外部接口、内部接口（模块间命令/端点/数据结构） |
| 运行设计 | 运行模块组合、运行控制、运行时间 |
| 数据结构 | 逻辑结构、物理结构、数据结构与程序的关系 |
| 出错处理 | 出错信息、补救措施、系统维护 |

## 关键提示

- **架构图必须用 drawio**：模块依赖图 + 数据流图，标注模块间调用/数据关系
- 内部接口要明确（命令/端点/数据结构），禁止只写"模块 A 调用模块 B"
- 功能×模块矩阵是"需求→模块"的映射，保证每个功能有归属模块
