# 详细设计 检查清单

> 做详细设计时，每个模块逐项覆盖 13 项，不遗漏。

## 每个模块 13 项

```
程序描述 / 功能 / 性能 / 输入项 / 输出项 / 算法 / 流程逻辑 /
接口 / 存储分配 / 注释设计 / 限制条件 / 测试计划 / 尚未解决的问题
```

## 关键提示

- 模块 = 实际代码模块（按 `find src` 归类），类名与源码一致
- 与上层模块相同处简述（不重复照抄）
- 「接口」写清楚模块间接口（输入/输出/异常）
- 「流程逻辑」复杂处用 drawio/Mermaid 图，不重画已有图
- 「尚未解决的问题」= 代码缺口，标注成本/方案/影响
