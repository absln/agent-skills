# 业务需求文档 BRD 检查清单

> 做业务需求分析时，逐项覆盖，不遗漏。

## 必须覆盖的维度

| 维度 | 检查点 |
|------|--------|
| 项目概述 | 产品描述、产品功能摘要、用户特点、约束、假设依据 |
| 功能需求 | 每个功能：描述 / 输入 / 处理 / 输出 |
| 外部接口 | 用户接口、硬件接口、软件接口、通信接口 |
| 性能 | 可度量的性能指标（如响应时间、并发数） |
| 系统要求 | 可用性、安全性、可维护性、可转移性 |

## 关键提示

- 功能需求的「输入/处理/输出」要闭环（输入→处理→输出 能走通）
- 性能需求必须可度量，禁止"响应快""性能好"等空话
