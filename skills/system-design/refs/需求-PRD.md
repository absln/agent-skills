# 产品需求文档 PRD 检查清单

> 做产品需求定义时，逐项覆盖，不遗漏。

## 必须覆盖的维度

| 维度 | 检查点 |
|------|--------|
| 用户定位 | 角色描述、目标用户、用户需求（场景 + 动机） |
| 产品定位 | 产品概述、核心目标、产品结构、任务路线图 |
| 功能需求 | 每功能：功能描述 / 前置条件 / 需求描述 / 后置条件 / 补充说明 |
| 非功能需求 | 性能、可维护性、可靠性、安全性、安装性、兼容性 |
| 风险分析 | 风险、可能性、严重性、应对策略 |

## 关键提示

- 需求描述写「外部黑盒行为」，不写实现细节
- 每个功能点要有前置/后置条件（用户操作流程闭环）
- 非功能需求写可度量指标，禁止空泛表述
