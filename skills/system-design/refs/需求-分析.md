# 需求分析说明书 检查清单

> 做需求分析时，逐项覆盖，不遗漏。

## 必须覆盖的维度

| 维度 | 检查点 |
|------|--------|
| 功能范围 | 使用范围、适用系统、适用模块、变更类型 |
| 项目概述 | 功能需求、流程图、顺序图、状态图 |
| 功能说明 | 功能需求（Use Case 格式）、非功能需求 |

## Use Case 格式

```
功能名称 / 功能概述 / 优先级别 / 使用者 / 前置条件 / 后置条件 / 功能规则 / 流程描述
```

## 关键提示

- 复杂功能用流程图/顺序图/状态图表达，不要只写文字
- 每个 Use Case 前置/后置条件要闭环
